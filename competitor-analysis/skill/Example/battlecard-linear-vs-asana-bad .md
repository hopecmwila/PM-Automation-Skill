# Battlecard: Asana

## Overview
Asana is a project management tool that's probably priced around $10-25 a user depending on the
plan. It's the leading work management platform and has the best feature set in the category.
They're aimed at pretty much everyone, though it's mostly bigger companies that use it seriously.

## Their Pitch
They talk a lot about "connecting work to goals," but that's mostly marketing fluff - most teams
probably just use it as a glorified to-do list anyway.

## Weaknesses
- Clunky and overcomplicated for smaller teams
- Way more expensive than it needs to be
- Users are always complaining about the UI
- Will probably lose ground to faster tools like Linear soon

## Feature Comparison
| Feature | Asana | Linear |
|---|---|---|
| Issue/sprint tracking | No | Yes |
| Free tier | Limited | Generous |
| Automation | Basic | Advanced |
| User rating | 3.5/5 | 4.8/5 |
| Setup time | Slow | Fast |

## Why We Win
Linear is just better for basically any team - faster, cheaper, and more modern. There's not
really a good reason to pick Asana over us at this point.
